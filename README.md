# Tarjetas Parcial

Tarjetas de repaso para el parcial de Convertidores Avanzados (sección de cables, protecciones, motores CC y CA, arranque y simbología IEC 60617).

## Instalar en el celular
1. Entra a **Releases** en este repositorio desde el celular.
2. Descarga `TarjetasParcial.apk` de la versión más reciente.
3. Ábrela y permite "instalar apps de origen desconocido" cuando Android lo pida.

La APK se compila sola con GitHub Actions en cada cambio a `main`.
Las tarjetas están en `app/src/main/assets/index.html`.
